# Maharaja Travels

Premium UK-based travel agency offering flight booking, visa assistance, tour planning, and travel consultation for international destinations worldwide.

## Features

- **Flight Booking**: Competitive rates for international and domestic flights.
- **Visa Assistance**: Professional guidance for visa applications.
- **Tour Planning**: Bespoke itineraries tailored to your needs.
- **24/7 Support**: Dedicated assistance for all your travel requirements.

## Tech Stack

- **Frontend**: React + TypeScript + Vite
- **Styling**: Tailwind CSS + Shadcn/UI
- **Icons**: Lucide React
- **Animations**: Framer Motion / Tailwind Animate

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`
4. Build for production: `npm run build`
